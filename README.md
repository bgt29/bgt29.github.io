# Личная страница

Простой одноэкранный сайт: аватар, пара строк о себе и крупные ссылки на соцсети.
Без сервера и без базы — только HTML/CSS/JS, поэтому бесплатно живёт почти где угодно.
Есть одна команда сборки — см. раздел «Сборка» ниже.

```
personal-site/
├── index.html            ← разметка; блок в <head> пишет сборка
├── 404.html              ← страница «не найдено»
├── favicon.ico           ← иконка вкладки, рисует сборка
├── en/index.html         ← английская версия; целиком делает сборка, руками не править
├── portfolio/            ← портфолио, разделы, работы (и en/portfolio/); целиком делает сборка
├── portfolio-src/        ← ★ оригиналы фото для портфолио; на сайт НЕ выкладываются
├── avito/index.html      ← страница-переброс на Авито (см. раздел 2)
├── privacy/index.html    ← конфиденциальность и куки (нужна, когда включишь Метрику)
├── admin/index.html      ← админка: правка конфига с телефона (см. раздел 6)
├── CNAME                 ← домен сайта для GitHub Pages
├── assets/
│   ├── css/style.css     ← оформление
│   ├── fonts/            ← шрифты Unbounded и Onest (лицензия OFL рядом)
│   ├── js/config.js      ← ★ ВЕСЬ КОНТЕНТ ЗДЕСЬ ★
│   ├── js/icons.js       ← логотипы соцсетей
│   ├── js/i18n.js        ← язык страницы: выбирает русский или английский текст
│   ├── js/theme.js       ← палитра: яркость и акцент
│   ├── js/panel.js       ← панель оформления
```

## Сборка — после любых правок конфига

```bash
cd C:/Users/Kirill/personal-site && powershell -ExecutionPolicy Bypass -File tools\build.ps1
```

Зачем она нужна. Страница рисуется скриптами, но **боты мессенджеров и
поисковики скрипты не выполняют** — они читают HTML как есть. Если не вписать
заголовок, описание и теги превью в сам файл, ссылка в Telegram придёт голой,
а поиск увидит пустую страницу «Личная страница».

Что делает сборка:

- вписывает в `index.html` (между метками `build:meta`) заголовок, описание,
  теги превью и разметку для поиска «это один человек, вот его профили»;
- рисует иконки: `favicon.ico`, `assets/img/favicon.svg` и иконку для экрана
  «Домой» на iPhone — первая буква имени в фирменном градиенте;
- рисует картинку превью `assets/img/og.jpg`;
- **вшивает содержимое страницы в HTML** — имя, проекты, все ссылки. Боты
  нейросетей скрипты почти никогда не выполняют, поисковики — не всегда; без
  этого они видели бы пустую страницу. Скрипт поверх всё равно перерисовывает
  страницу из конфига, так что правки видны и до сборки;
- пишет `robots.txt` (служебное `tools/` и `README.md` закрыты от поиска),
  `sitemap.xml` (когда заполнен `meta.url`) и `llms.txt` — краткую справку
  о тебе для нейросетей (стандарт llmstxt.org; что его читают, не гарантировано).

Для поиска по имени в разметке страницы указаны имя и фамилия отдельно и ник
как второе имя — так совпадают и «Кирилл Булдаков», и «Булдаков Кирилл», и «Baget».

Запускать после смены имени, описания, аватара или списка ссылок. Сама
страница у гостей обновится и без сборки, а вот превью и поиск — нет.

Если иконка или превью отрисуются пустыми, сборка остановится с ошибкой
и ничего не испортит. Нужны Python и Chrome или Edge — берёт тот, что найдёт.

## 1. Как менять содержимое

Открой **`assets/js/config.js`** в любом редакторе и правь текст между кавычками.

| Что хочу | Что делать |
|---|---|
| Имя, должность, описание | блок `hero` |
| Аватар | положи файл в `assets/img/`, укажи `avatar: 'assets/img/avatar.jpg'`. Пусто → будут инициалы |
| Добавить ссылку | скопируй строку в `links` и поменяй `icon`, `label`, `handle`, `url` |
| Убрать ссылку | удали её строку целиком |
| Поменять порядок ссылок | переставь строки местами — так они и отобразятся |
| Убрать плашку «Открыт к проектам» | `hero.status: ''` |
| Показать блок «Сейчас» | в `now` поставь `enabled: true` |
| Тема | `meta.theme` — `'auto'` (как у гостя в системе), `'light'` или `'dark'` |
| Иконка вкладки | рисует сборка из первой буквы имени; эмодзи вместо неё — `meta.favicon: '🌤'` |
| Почта | в строке почты есть кнопка «скопировать адрес» — для тех, у кого не настроен почтовый клиент |

**Доступные значения `icon`:** `telegram`, `github`, `gitlab`, `vk`, `x`, `instagram`,
`threads`, `youtube`, `linkedin`, `discord`, `tiktok`, `twitch`, `whatsapp`, `spotify`,
`behance`, `dribbble`, `habr`, `boosty`, `avito`, `itd`, `email`, `link`.
Незнакомое имя не сломает страницу — подставится иконка ссылки.

Логотипы лежат в `assets/js/icons.js` — это официальные контуры из проекта
[Simple Icons](https://simpleicons.org) (лицензия CC0). Исключение — `avito` и `itd`:
в Simple Icons их нет, они нарисованы вручную по фирменным знакам и помечены
комментарием в конце файла.

Нужен логотип, которого нет? Скачай контур и добавь строкой в тот же файл:

```bash
curl -s https://cdn.jsdelivr.net/npm/simple-icons@latest/icons/pinterest.svg
```

Из ответа возьми содержимое `d="..."` и впиши `pinterest: '<path d="..."/>',`

### Раздел «Проекты» (наверху)

Над профилями — раздел «Проекты», блок `projects` в `config.js`. Каждый проект —
крупная карточка с кнопкой; новый добавляется строкой в `items`. Сейчас там
VPN-бот `@EBK_KVN_BOT`. `enabled: false` убирает раздел целиком.

### Имя и ник

В шапке — `hero.name` (имя и фамилия на двух языках) и `hero.nick` (плашка
под именем: «Багет» на русской версии, «Baget» на английской). Отчество —
`hero.patronymic`: на странице его не видно, оно уходит в разметку для поиска,
справку для нейросетей и политику конфиденциальности. Ник без @: на каждой площадке он в своей форме, а общий корень у
всех один. Сборка вписывает для поиска «другие имена» (`alternateName`): имя на
втором языке, ник и его формы из `hero.aliases`, — чтобы находили по любому.
Подвал берёт имя из шапки сам, если `footer.text` пустой.

### Английская версия

Сайт на двух языках: русский — главная, английский — по адресу `/en/`.
Кнопка EN / RU стоит рядом с кнопкой оформления.

Английский текст пишется в `config.js` рядом с русским:

```js
label: { ru: 'Почта', en: 'Email' },
```

Где текст одинаковый (Telegram, GitHub, ник под ссылкой), хватает одной строки. Добавил
ссылку — пиши сразу оба варианта. Забыл английский — на английской странице
будет русский, а сборка в конце напишет, какой строки не хватает.

Английскую страницу `en/index.html` целиком делает сборка: свой заголовок,
описание, картинка превью `og-en.jpg` с именем латиницей и пометки для
поисковиков, что это одна страница на двух языках. Поэтому после правок
конфига — **сборка**, как обычно. `english.enabled: false` — сайт только на
русском: кнопка пропадёт, сборка уберёт `/en/`.

Почему отдельный адрес, а не переключение на месте: поисковики читают то,
что лежит на странице сразу, и кнопок не нажимают. Английский текст, который
появляется только по кнопке, они бы не увидели.

### Знак EBK KVN

Знак собран не из картинки, а из трёх трафаретов в `assets/img/ebk`: стрелка,
«ebk» и «kvn bot». Цвет им даёт тема, поэтому на светлой знак в родных цветах
бренда, а на тёмной выворачивается — буквы становятся кремовыми, цветом фона
оригинального логотипа. Жёлтый курсор — отдельный элемент: мигает, как в
терминале, а при наведении загорается ровно. Цвета бренда — переменные
`--ebk-*` в `style.css`.

Если поменяется логотип — трафареты придётся вырезать заново: разложить
исходник на слои по цвету и снять положение курсора в долях кадра.

Убрать `logo: 'ebk'` — и карточка станет обычной выделенной, со значком `icon`.
Так её можно отдать под что-то другое.

### Внешний вид: плитки

Главная собрана из плиток (выбор Кирилла 23.10.2026, вариант «Плитки»):

- **слева вверху** — большая плитка с фото, именем, ником и описанием. Строка
  описания с «·» показывается плашками (`Сборка ПК · Сайты · …`), остальные —
  текстом;
- **справа** — ссылка с `featured: true` большой цветной плиткой (сейчас
  Telegram-профиль) и проекты (VPN-бот — тёмной плиткой);
- **ниже** — плитки ссылок по четыре в ряд (на телефоне по две), значок —
  в фирменном цвете соцсети. Последняя плитка группы сама добирает пустое
  место в ряду. Плитка «Портфолио» стоит последней в первой группе.

Шрифты — Unbounded (имя, названия плиток, заголовки) и Onest (текст). Лежат на
самом сайте в `assets/fonts` вместе с лицензией OFL, с Google не грузятся.

### Пасхалки

Код — в `assets/js/eggs.js`, стили — в конце `style.css` (раздел «Пасхалки»).

1. **RGB-режим** — три быстрых нажатия на кнопку оформления. Рамки плиток
   переливаются радугой, плитка Telegram перебирает цвета, вокруг аватара —
   кольцо ARGB-подсветки со свечением (само фото не перекрашивается).
   Запоминается в браузере гостя; выключается так же или командой `rgb`
   в терминале.
2. **Терминал** — нажатие на мигающий жёлтый курсор в знаке EBK KVN (обычное
   нажатие на плитку по-прежнему ведёт к боту). `help` показывает команды:
   `about`, `links`, `vpn`, `portfolio`, `neofetch`, `theme light|dark`,
   `rgb`, `clear`, `exit`. Секретные, в `help` их нет: `sudo …`,
   `rm -rf`, `багет` / `baget` (запускает багетопад), `кофе` / `coffee`
   (варит кофе: полоска готовности, чашка и случайная фраза — фразы в
   `UI.coffee`), `чай` / `tea`, `привет` / `hello`. Новая команда — ещё один
   `case` в функции `run`.
3. **Багетопад** — пять быстрых нажатий подряд на плашку с ником. Одинаково
   на компьютере и на телефоне. Багет нарисован свой: эмодзи на Windows —
   плоская жёлтая палочка.

Кто в системе выключил анимацию, получает всё без движения: рамки не крутятся,
багеты не падают — только подсказка вверху экрана.

### Панель оформления

Кнопка в правом верхнем углу открывает панель: ползунок яркости на пять
ступеней (Ночь → Тёмная → Сумерки → Светлая → Дневная) и выбор акцентного
цвета. Выбор запоминается в браузере **у гостя** и на других не влияет —
у всех остальных сайт открывается в родной тёплой гамме.

Список цветов — в `config.js`, блок `appearance.accents`. Первый в списке
считается родным и стоит по умолчанию. `enabled: false` убирает панель совсем,
и кнопка просто переключает светлую и тёмную тему.

Палитра целиком считается из двух вещей — уровня яркости и акцента
(`assets/js/theme.js`). Карточки, обводки, текст и фоновые пятна выводятся из
них, поэтому новый цвет в списке не требует правки CSS.

### Поменять цвета

Родной цвет сайта — **первый** в списке `appearance.accents` в `config.js`
(сейчас терракота). Поменяй там `accent` и `accent2` — и он станет цветом по
умолчанию для всех. Остальное — фон, карточки, текст — `theme.js` выведет сам.

Блоки `:root` и `[data-theme="dark"]` в `style.css` — только запасной вариант
на случай, если скрипты не загрузились. Править их ради смены цвета не нужно.

### Аватар

Положи квадратное фото в `assets/img/avatar.jpg` — оно подхватится само,
путь уже прописан в конфиге. Чтобы поменять фото потом, просто замени файл
тем же именем, в коде править нечего. Если файла нет или он битый, вместо
него покажется первая буква имени — сайт не сломается.

Годится `.jpg`, `.png`, `.webp`. Разумный размер — около 512×512: в круге
104 пикселя больше не нужно, а вес страницы это экономит заметно. Кадр лучше
брать поплотнее — общий план в маленьком круге читается плохо.

**Свечение под аватаром подстраивается под фото.** Движок считает средний цвет
снимка, подмешивает акцент палитры и удерживает результат в тёплом секторе:
ореол перекликается с картинкой, но не выбивается из оформления. Меняешь
фото — свечение пересчитывается само. Логика в `app.js`, функция
`tuneAvatarGlow`; тёплый диапазон задан в `toWarm`.

### Картинка превью

Это то, что видит человек, когда ты кидаешь ссылку в Telegram, VK или в
объявление. Лежит в `assets/img/og.jpg`, размер 1200×630, около 40 КБ.

Рисуется сборкой из того же `config.js` — имя, описание, аватар и логотипы
ссылок (каждый значок по одному разу). Вручную её делать не нужно.

**Важно:** мессенджеры подтягивают картинку только по полному адресу. Пока
`meta.url` в конфиге пустой, превью работать не будет. После публикации впиши
туда адрес сайта, например `https://bgt29.github.io`, **запусти сборку** —
и тогда заработает.
Если поменял картинку, а превью осталось старым, у мессенджера свой кеш:
у Telegram он сбрасывается ботом `@WebpageBot`, у VK — на странице
`vk.com/dev/pages.clearCache`.

### Портфолио

Под описанием появляется переключатель «Ссылки | Портфолио» — **сам, как только
в конфиге есть хоть одна работа**. Пока работ нет, нет ни вкладки, ни страниц —
если только не включён `portfolio.showEmpty: true`. С ним вкладка и все ряды
видны и без работ, в пустом ряду карточка «Скоро здесь появятся работы», а
страница закрыта от поиска. Сейчас он включён, пока сайт не опубликован:
**перед публикацией** добавь работы или поставь `false` — сборка напомнит.

Как устроено:

- `/portfolio/` — по ряду-карусели на каждый раздел (Собранные ПК, Фото,
  Сайты, Внедрение ИИ). Карточки почти во всю ширину, ряд листается вбок,
  у ряда ссылка «Все →». Одна работа в разделе — карточка во всю ширину.
- `/portfolio/pc/` — страница раздела со всеми его работами.
- `/portfolio/pc/имя-работы/` — страница работы: фото листаются, ниже текст,
  характеристики и «Ещё в разделе». Её удобно давать ссылкой, например
  в объявлении на Авито, и поисковики находят каждую работу отдельно.

Раздел без работ не показывается. Новый раздел — строка в
`portfolio.categories`: `id` латиницей (он же часть адреса) и название на двух
языках. Все эти страницы, на русском и английском, делает сборка; если работу
удалить из конфига, сборка уберёт и её страницы.

Как добавить работу:

1. Создай папку `portfolio-src\имя-работы` — латиницей, цифрами и дефисом,
   например `gaming-pc-4070`. Положи туда фото в JPG или PNG. Порядок — по
   имени файла (`1.jpg`, `2.jpg` … `10.jpg`), первое фото — обложка.
2. В `config.js`, блок `portfolio.items`, допиши работу — образец там же.
   `id` — то же имя, что у папки. Раздел (`category`) — из списка выше
   в конфиге. `date` — год и месяц: свежие работы стоят первыми.
3. Запусти сборку.

Сборка уменьшает фото (1600 точек для страницы работы, 640 для карточки),
поворачивает «боковые» снимки с телефона и стирает служебные данные — модель
телефона, дату и место съёмки. Оригиналы остаются в `portfolio-src` и на сайт
не выкладываются. Фото с iPhone в HEIC сборка не читает — подробно
в `portfolio-src\ПРОЧТИ.txt`. Ошибки — нет фото, неверный раздел, забытый
перевод — сборка покажет в конце.

**Видео** (раздел «Видео», рилсы) кладётся в папку работы так же, как фото:
MP4, MOV, M4V или WEBM. Сборка пережимает ролик через ffmpeg — до 1280 точек
по длинной стороне, со стёртыми данными телефона, — и он играет прямо на сайте,
без YouTube и VK. Обложка — кадр из ролика. Если нужна своя, положи рядом
картинку с тем же именем: `reel-1.mov` + `reel-1.jpg`. Картинка станет
обложкой и отдельным фото в галерею не попадёт. Лучше, чтобы пропорции
обложки совпадали с роликом. Без ffmpeg (`winget install ffmpeg`) сборка
пропустит видео и скажет об этом в конце.

Для сайта, видео или поста в работе есть поле `url`: на странице работы появится
кнопка — для поста в Telegram «Пост в Telegram», в Instagram «Пост в Instagram»,
в «Сайтах» «Открыть сайт», в остальных «Подробнее» (или своя надпись в `cta`).
Превью ссылки на работу в мессенджерах — её обложка.

У раздела может быть `more` — куда звать за продолжением, одной ссылкой или
списком. Предложение услуги (`offer: true`, ведёт в личный Telegram: «Могу
собрать ПК…», «Могу устроить фотосессию», «Могу снять и смонтировать видео»)
стоит плашкой сразу под заголовком раздела, над кейсами. Канал («Про ПК»,
Instagram, YouTube) — карточкой последней в ряду. Он появляется карточкой последней
в ряду и на странице раздела и плашкой на странице каждой работы. Раздел
без работ, но с `more` тоже виден: вместо «Скоро здесь появятся работы»
в нём эта плашка. У «Сайтов» и «Внедрения ИИ» `more` ведёт в личный Telegram:
«Могу разработать…».

`org` у раздела — подпись, где сделаны работы, со ссылкой на сайт компании.
У «Сайтов» и «Внедрения ИИ» под заголовком ряда и в шапке раздела —
«Делаю сам и в команде «Онлайн-Сервис»». У работы, которая была заказом
компании, поставь `team: true` — на её странице появится «Сделано в команде
«Онлайн-Сервис»». У своих проектов `team` не ставь — строки не будет.

### Подвал

Строка внизу — имя из шапки на языке страницы и год. По нажатию ведёт туда,
что вписано в `footer.url` (сейчас Telegram-профиль). Пусто — просто текст.

### Статистика и уведомление о куки

Пока счётчика нет, сайт **ничего не собирает** — поэтому и уведомления нет:
писать «мы используем куки», когда их нет, было бы неправдой.

Включить Яндекс.Метрику:

1. Зайди на metrika.yandex.ru → «Добавить счётчик». Адрес — адрес сайта,
   **Вебвизор не включай**, остальное по умолчанию.
2. Скопируй номер счётчика (только цифры) в `analytics.metrika` в конфиге.
   Код счётчика со страницы Метрики вставлять **не нужно** — сайт подключит
   его сам.
3. Запусти сборку, как после любых правок. Появятся:
   - внизу экрана уведомление «Принять / Отказаться»; Метрика включается
     **только после «Принять»**, ответ запоминается в браузере гостя;
   - ссылка «Конфиденциальность и куки» в подвале, она ведёт на `/privacy/`.
     Там написано, что собирается и зачем, и есть кнопки, чтобы передумать.
     При отказе куки Метрики на сайте стираются.

Какие ссылки открывают, видно в Метрике: «Отчёты → Содержание → Внешние
переходы».

**Второй счётчик, без куки — GoatCounter** (`assets/js/count.js`). Метрика
видит только тех, кто нажал «Принять»; GoatCounter считает всех: просмотры,
откуда пришли, нажатия на ссылки наружу (событиями: `t.me/Baget_PC`,
`mailto`, `avito`), браузер, экран, страну. Куки не ставит, у гостя ничего
не хранит — поэтому уведомление для него не нужно. Включить:

1. Зарегистрируйся на goatcounter.com, при создании сайта придумай код —
   из него получится адрес статистики `КОД.goatcounter.com`.
2. Впиши код в `analytics.goatcounter` в конфиге и запусти сборку.

Считает только на адресе из `meta.url` — проверки на компьютере и сама
сборка в статистику не попадают. На `/privacy/` про него появится раздел
«Счётчик без куки». Имя и почта на странице политики берутся из конфига; если
заполнишь `hero.patronymic`, там будет полное ФИО. Поменял текст политики
в `privacy/index.html` — обнови дату редакции наверху.

## 2. Ссылка на Авито, которая не ломается

Авито периодически меняет адрес профиля, поэтому карточка ведёт не прямо туда,
а на свою страницу `/avito`. Та берёт настоящий адрес из `config.js` и перебрасывает
дальше.

Что это даёт: наружу ты раздаёшь **`https://твой-сайт/avito`** — эту ссылку можно
вставить хоть в шапку профиля, хоть в объявление, и она никогда не протухнет.
Когда Авито в очередной раз сменит адрес, правишь одну строку `redirectTo`
в `config.js` — и всё, старая ссылка продолжает работать.

```js
{ icon: 'avito', label: 'Avito', handle: 'Мои объявления',
  url: '/avito',
  redirectTo: 'https://www.avito.ru/user/НОВЫЙ_АДРЕС/profile' },
```

Тот же приём подойдёт для любой другой ссылки, которая любит меняться:
скопируй папку `avito` под новым именем и поменяй в ней `icon === 'avito'`
на нужный.

3. **Включить Pages**: репозиторий → Settings → Pages → Source: Deploy from

## 5. Мелочи

- **Тема** — при первом заходе подхватывается системная настройка гостя
  (тёмная тема на телефоне → сразу тёмный сайт). Дальше работает переключатель
  в правом верхнем углу, и его выбор запоминается в браузере — системная
  настройка больше не перебивает. Чтобы всегда открывалась одна тема,
  поставь в `config.js` → `meta.theme` значение `'light'` или `'dark'`.
- **Фон** — мягкий тёплый градиент из трёх пятен, у каждой темы свой.
  Настраивается переменными `--glow-1/2/3` в начале `assets/css/style.css`.
- **Ссылки** — все открываются в новой вкладке, включая почту, чтобы страница
  не закрывалась под гостем. Задаётся в `assets/js/app.js`, функция `renderLinks`.
- **Размер логотипов** — выравнивается сам. Логотипы нарисованы разными людьми:
  один упирается в края квадрата, другой сидит с полями, третий шире, чем выше.
  Функция `normalizeIcons` в `app.js` меряет реальные границы каждого рисунка
  и приводит все к одной площади, сохраняя пропорции. Новый значок подхватится
  автоматически — подгонять руками ничего не нужно.
- **Аватар** — квадратная картинка от 400×400, `.jpg` / `.png` / `.webp`.
- **Доступность** — фокус с клавиатуры, уважается системная настройка «меньше анимации».

## 6. Админка — правки с телефона

`https://kirillbuldakov.ru/admin/` — страница для правки `config.js` прямо в
репозитории, без компьютера со сборкой. В поиске её нет (`noindex` и запрет
в `robots.txt`), ссылок на неё с сайта тоже нет.

- **Вход** — ключом GitHub: Settings → Developer settings → Fine-grained
  tokens → только репозиторий сайта → Permissions: **Contents: Read and write**,
  больше ничего; срок — 90 дней. Без галочки «Запомнить» ключ забывается
  с закрытием вкладки. На чужом устройстве галочку не ставь, после работы —
  «Выйти».
- **Быстрые поля** — ссылка на Авито (дата пометки «проверено» обновится
  сама), код GoatCounter, номер Метрики.
- **Весь конфиг** — текстом. «Проверить и показать изменения» выполняет
  конфиг и ловит ошибки (кавычки, запятые, работа без раздела); с ошибкой
  сохранить нельзя. Перед сохранением видно, какие строки изменятся.
- **Сохранение** — правкой (коммитом) в `main`, сайт обновляется через 1–2
  минуты. Если файл успели поменять в другом месте, GitHub правку не примет
  и ничего не затрётся: «Отменить правки» загрузит свежий файл.
- **Что админка не умеет** — фото и видео, заголовки для поиска, превью
  ссылок, `sitemap.xml`: это делает только сборка на компьютере. Тексты и
  ссылки на самих страницах обновляются и без неё: страница перерисовывается
  из `config.js`.
- **Защита** — на странице строгие правила (CSP): свои скрипты и связь только
  с `api.github.com`, ключ никуда больше уйти не может. Ни Метрики, ни
  счётчика на ней нет. Код — `admin/index.html` и `assets/js/admin.js`.
- Ключ утёк или потерян телефон — GitHub → Fine-grained tokens → **Revoke**.
