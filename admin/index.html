Админка

Правка ссылок и текстов сайта прямо отсюда — без компьютера со сборкой.

Вход

Без галочки ключ забудется, когда закроете вкладку. Ставьте её только на своём телефоне или компьютере.

Где взять ключ
  1. GitHub → фото профиля → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Expiration — 90 дней (потом сделаете новый).
  3. Repository access → Only select repositories → репозиторий сайта.
  4. Permissions → Repository permissions → Contents: Read and write. Больше ничего не включайте.
  5. Generate token, скопируйте и вставьте сюда. GitHub показывает его один раз.

Быстрые правки

Авито иногда меняет адрес профиля — сюда новый, сайт и переходник /avito подхватят его сами.

Весь конфиг

Файл assets/js/config.js целиком: ссылки, тексты, портфолио. Быстрые правки выше пишут сюда же.

Сайт обновится через 1–2 минуты после сохранения. Фото, видео, заголовки для поиска и превью ссылок меняются только сборкой на компьютере — перед ней сделайте git pull, чтобы забрать правки отсюда.
